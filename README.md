## 💻 What I'm Learning

I am building a strong foundation in front-end web development. Through my lab exercises, I am learning to:

- Structure web pages using valid **HTML5** and semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Implement ordered, unordered, and description lists, along with absolute, relative, and e-mail hyperlinks.
- Embed multimedia content using `<video>` and `<source>` tags.
- Apply **CSS** using inline, internal, and external style sheets, including ID and class selectors.
- Design visually appealing layouts using CSS backgrounds (`background-image`, `background-size: cover`), Google Fonts, and text formatting (`text-align: justify`, `line-height`).
- Build interactive navigation bars with hover and active states, and style data tables with alternating row colors and hover effects.
- Validate code using the **W3C Validator** (HTML) and **Jigsaw Validator** (CSS).
